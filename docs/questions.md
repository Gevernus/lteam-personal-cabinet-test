# Вопросы и критерии готовности

## Нужно решить перед реализацией

1. Какой конкретно desktop-фрейм и соответствующий mobile-фрейм берём?
2. «Под Laravel» означает Laravel Vite entrypoint/Blade или достаточно переносимых Vue-компонентов?
3. Нужна только визуальная вёрстка или интерактивность и валидация тоже?
4. Разрешены ли внешние icon/font packages, либо всё экспортировать из Figma?

## Definition of Done

- Выбранные desktop/mobile фреймы зафиксированы ссылками или скриншотами.
- Вёрстка совпадает по сетке, типографике, цветам и состояниям.
- Нет горизонтального overflow от 320 px.
- Интерактивные элементы доступны с клавиатуры и имеют focus state.
- Нет inline styles и inline event handlers.
- Каждый `.vue`-файл короче 300 строк.
- `npm run build` проходит.
- Git-репозиторий опубликован, Vercel preview открывается без ошибок.
- В README описан вариант подключения к Laravel.
