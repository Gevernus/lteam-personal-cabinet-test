# Краткое ТЗ

Источник: переписка аккаунта Киры с `@lteam063`, 17 сентября 2026.

## Результат

1. Выбрать **любой один экран** личного кабинета из Figma.
2. Реализовать его в вариантах **desktop + mobile**.
3. Отправить ссылку на Git-репозиторий и Vercel preview.
4. Код сразу организовать так, чтобы его можно было использовать с Laravel.

## Обязательные правила

1. Интерфейс разбивать на компоненты; даже кнопка должна быть компонентом.
2. Один компонент — один файл.
3. Имя файла: доменное имя + назначение, например `personal_cabinet_button.vue`.
4. Не более 300 строк в файле.
5. Компоненты должны быть переиспользуемыми.
6. Vue Composition API в сокращённом формате (`<script setup>`).
7. Не использовать inline JavaScript и inline CSS.
