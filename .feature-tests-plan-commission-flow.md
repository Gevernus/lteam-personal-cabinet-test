# Feature-test plan: commission flow

Режим: UI (Vue 3 / Vite). План составлен до реализации в auto-режиме.

## Контракт

| Раздел | Поле/состояние | Ограничения | Источник |
|---|---|---|---|
| Input | viewport | 320px+; без horizontal overflow | spec §2 |
| Input | keyboard | Tab, Enter/Space, Escape | spec §6–7 |
| Input | Clipboard API | success или reject/unavailable | spec §5 |
| State | commission | step 2, total и breakdown | spec §4 |
| State | coordinates | step 3, payment details | spec §5 |
| State | confirmed | успешное локальное подтверждение | spec §6 |
| State | closed | dialog отсутствует; launcher доступен | spec §6 |
| Output | total | сумма строк = 3700 cents | spec §4 |
| Side effect | clipboard | копируется только выбранное значение | spec §5 |
| Side effect | focus | dialog title on open; launcher on close | spec §6 |
| Dependency | browser | clipboard, matchMedia, DOM focus | spec §5–7 |
| Assumption | data | monetary values stored as integer cents | architecture |

## Properties

| Категория | Property | Инструмент |
|---|---|---|
| Format compliance | `formatEuro(cents)` соответствует Italian euro format | fast-check |
| Determinism | одинаковые cents дают одинаковую строку | fast-check |
| Value constraint | parse(format(cents)) возвращает исходное число cents | fast-check |
| Conservation | сумма fee items равна declared total | unit invariant |
| Ordering | отображение fee items сохраняет spec order | component query |
| Idempotency | repeated state reset остаётся в commission | interaction |
| Uniqueness | разные clipboard controls копируют разные exact values | interaction |
| Inverse | format→parse round-trip для диапазона 0..1e9 cents | fast-check |

## Regression proof

Новая фича создаётся TDD. Contract-тест запускается до реализации и должен завершиться RED из-за отсутствующих компонентов. После GREEN proof фиксируется в `docs/qa-report.md`.
